# 字体文件目录

此目录用于存放思源黑体（Source Han Sans SC）字体文件。

## 需要的字体文件

请下载以下 WOFF2 格式的字体文件并放入此目录：

- `SourceHanSansSC-Light.woff2` (字重 300)
- `SourceHanSansSC-Regular.woff2` (字重 400)
- `SourceHanSansSC-Medium.woff2` (字重 500)
- `SourceHanSansSC-SemiBold.woff2` (字重 600)
- `SourceHanSansSC-Bold.woff2` (字重 700)

## 下载来源

### GitHub 官方
https://github.com/adobe-fonts/source-han-sans/releases

下载 `SourceHanSansSC.ttf` 或 `SourceHanSansSC.woff2` 压缩包，解压后选择需要的字重。

### 清华大学镜像站
https://mirrors.tuna.tsinghua.edu.cn/github-release/adobe-fonts/source-han-sans/

### 字体转换

如果下载的是 OTF 或 TTF 格式，可以使用以下工具转换为 WOFF2：
- https://cloudconvert.com/otf-to-woff2
- https://transfonter.org/

## 文件命名规范

请确保文件名与以下格式一致：
- `SourceHanSansSC-Light.woff2`
- `SourceHanSansSC-Regular.woff2`
- `SourceHanSansSC-Medium.woff2`
- `SourceHanSansSC-SemiBold.woff2`
- `SourceHanSansSC-Bold.woff2`
